Luxury Car Image Gallery 🚗

A modern and responsive Luxury Car Image Gallery Web App built using HTML5 and CSS3.
This project showcases beautiful luxury car images with smooth hover animations, zoom effects, fade overlays, and interactive captions.

✨ Features
Responsive image gallery layout
Smooth image zoom hover effects
Fade overlay animations
Captions appearing on hover
Clean and minimal UI design
Mobile-friendly responsive design
CSS Grid based layout
Modern card styling

HTML5
CSS3

Responsive Web Design
